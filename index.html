git init

◎

Inicializa un nuevo repositorio local en la carpeta actual. Es el primer paso para empezar a trackear tu proyecto.

$ git init
02

git clone

◎

Descarga una copia exacta de un repositorio remoto, incluyendo todo su historial de cambios.

$ git clone <url>
03

git add

◎

Prepara los cambios (staging) para ser incluidos en el próximo commit. Usa git add . para agregar todo.

$ git add .
04

git commit

◎

Guarda los cambios preparados en el historial del repositorio con un mensaje descriptivo.

$ git commit -m "mensaje"
05

git branch

◎

Lista, crea o elimina ramas. Las ramas permiten trabajar en paralelo sin afectar el código principal.

$ git branch <nombre-rama>
06

git merge

◎

Une los cambios de una rama con otra. Combina el trabajo de diferentes desarrolladores en una sola línea.

$ git merge <rama>
07

git push

◎

Envía tus commits locales al repositorio remoto para compartir tu trabajo con el equipo.

$ git push origin <rama>
08

git pull

◎

Descarga e integra los cambios del repositorio remoto en tu rama local. Combina fetch + merge.

$ git pull origin <rama>
